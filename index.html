Auto power-off

The headset counts down while it hears silence — quiet audio counts as silence, which is why it switches off while you're still listening. Never turns the timer off completely.

Custom timer (unofficial)

The firmware field is 16-bit seconds (0–65535, about 18 h). NGENUITY only ever sends the four values above, so other values are untested — after applying, the read-back shows what the headset kept.

Voice promptsSpoken "power on", "battery low", … announcements.
Playback mute experimentalMutes the headset's speakers on the headset side.
Noise cancellation? The Cloud III S has no active noise cancellation, and neither NGENUITY version has a noise-cancelling command for it. The mic's noise reduction is acoustic (built into the mic). The "noise suppression" in NGENUITY 3 is PC-side processing in its own audio driver — without NGENUITY it simply isn't there.

Settings & troubleshooting
  • Nothing answers / everything shows "—": turn the headset on, make sure it's paired with the dongle (status "Headset link"), and close NGENUITY. Unplug and replug the dongle if it stopped answering.
  • Linux: install linux/99-hyperx-cloud3s.rules for permissions. Some kernels confuse the dongle on first enumeration so it stops forwarding replies; see the README for the usbcore.quirks fix.
  • The headset must be on and in 2.4 GHz mode. Over Bluetooth there's no control channel to the PC.
  • Spatial audio (DTS) and the volume sliders in NGENUITY are PC-side features, not headset settings — nothing to replicate here.
